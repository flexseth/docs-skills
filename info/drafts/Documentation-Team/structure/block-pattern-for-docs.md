[#474](https://github.com/WordPress/Documentation-Issue-Tracker/issues/474) | [HelpHub] Create a block pattern for Block Documentation | Process & contributor tasks

To make block documentation more consistent and speed up its creation, create a reusable block pattern containing the core components common to most block documentation.

The pattern should include:

- Intro
- Steps
- Block Toolbar
- Block Settings

Documentation contributors can add the pattern to a new document and fill in the details.
