## Suggested Improvement

Use labels to classify changes needed by documentation source: 
- screenshot
- new
- bug
- enhancement
- spelling and grammar
- blocks
- settings

Which relate to the various handbook sections.

## Reworking Issues Labels

Remove all labels and use only the following lables: 
- screenshot
- new
- bug
- enhancement
- spelling and grammar
- blocks
- settings
-

Labels are automatically pulled from the URL in the issue or pull request, ensuring consistency with the source of truth.

Multiple labels can be used, if the documentation exists in multiple areas or covers multiple aspects of the handbook.

The Labels match the handbook surface or where the source of truth lives.
