# GitHub and Slack user accounts in WordPress

The purpose of this integration is to bring in user: 
- Emails
- Profile Names
- Slack Handles
- GitHub Handles
- GitHub Profile Pictures - for Gravatars
- GitHub Email Address - for commits

## How do we use these?

**Authentication** 

- provide login and user verification across GitHub, Slack, and WordPress
- sign commits
- automatically create WordPress user accounts based on GitHub email with handle as username


**GitHub Actions** for automated workflows and notifications

- Give Props via PropsBot once changes are made.
- Tag users in Slack or GitHub for review or changes
- Further improve the tightness of the integration with the existing Documentation and Workflows
- Block notes create comments on PR for review or to request changes
