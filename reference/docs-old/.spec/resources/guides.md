# WordPress.org Documentation Resource Guides - "HelpHub"

Helpful articles for end users, AKA "HelpHub," from [wordpress.org/documentation](https://wordpress.org/documentation/).

The content for these guides and resources live on wordpress.org, and only those with Editor access may contribute.

Currently there is no existing review process, other than being a vetted contributor with Editor access.
