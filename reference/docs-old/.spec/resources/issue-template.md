## Docs Update Issue Template

From: https://github.com/WordPress/Documentation-Issue-Tracker/issues/2126

**Backstory**

This is a long standing updates template for new WordPress releases, as they refer to the changes in Blocks.

It is not a comprehensive list, but rather a guideline to help ensure that documentation stays current with each WordPress release. It covers block specific updates only. It does not cover Admin pages, settings pages, themes, or other non-block related changes.

## Template

Given a new version of WordPress, here are some steps to follow to ensure the documentation is up to date:

To update each block article and update them to WP release <WP_VERSION>, follow the instructions below:

1. Review the reference issues and PRs that have been added to the article.
2. Make any valid updates from previous releases. If those updates are no longer relevant, close the the issue (NOTE: we can only close issues in the Documentation Issue Tracker, feel free to leave a comment in the Gutenberg repository so a PR can be closed)
3. The name of the block should be in regular font and not in italics or bold, if you find any italics or bold, change the font
4. Update screenshots and videos with the latest version
5. Do NOT hotlink images, take the screenshots and upload then to the documentation site in WordPress
6. Make sure all headings are in sentence case, NOT title case (e.g. "Block toolbar" ✔️  ; "Block Toolbar" ❌ )
7. Update the Change log and add updater's WP.org username and any other contributors that have given feedback/solution even if it wasn't used (eg. updated by @estelaris @zzap) 
8. When you are done updating a block article, mark them in the list belowIf you cannot edit articles in  WordPress.org/documentation, ping @estelaris in #docs Slack for access.
