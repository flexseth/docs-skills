# Rubric 03: Maintenance Banner (Settings and Options API)

## Doc surfaces the prompt depends on
- Complex: Settings API (`register_setting`, `add_settings_section`, `add_settings_field`, `settings_fields`, `do_settings_sections`, `add_settings_error`)
- Non-general: `register_setting` with `show_in_rest` + schema for `/wp/v2/settings`; `useEntityRecord` / `saveEditedEntityRecord` on `root/site`
- `add_options_page`
- `wp_kses`, `sanitize_hex_color`, `wp_roles()`
- `registerPlugin` / `PluginSidebar`, `useSelect` + core store `canUser`
- `wp_body_open`, `uninstall.php` / `register_uninstall_hook`

## Criteria (1 point each unless noted)
1. Options page added with `add_options_page` and `manage_options` capability.
2. `register_setting` for `maintenance_banner_options` with `type: 'object'`, `sanitize_callback` and `default`.
3. `show_in_rest` includes a `schema` with `properties` for every field.
4. Section and fields registered with `add_settings_section` / `add_settings_field`; form uses `settings_fields()` and `do_settings_sections()` posting to `options.php`.
5. Sanitize callback: checkbox to bool, message through `wp_kses` with an allowed list, colour via `sanitize_hex_color`, datetimes validated, roles intersected with `wp_roles()` keys.
6. `add_settings_error()` when end is before start (and keeps old value or clears the bad one).
7. Field callbacks escape output (`esc_attr`, `esc_textarea`, `checked()`).
8. Sidebar registered with `registerPlugin` + `PluginSidebar` (from `@wordpress/editor` or `@wordpress/edit-post`).
9. Reads/saves via `useEntityRecord( 'root', 'site' )` (or `useEntityProp( 'root', 'site', ... )`) and `saveEditedEntityRecord`.
10. Sidebar gated by `canUser( 'update', ... )` / `manage_options` check via `useSelect`.
11. Front end hooks `wp_body_open`, checks enabled + time window (site timezone) + user roles.
12. Banner output escaped (`wp_kses_post`/`wp_kses` for message, `esc_attr` for colour).
13. Uninstall deletes the option (`uninstall.php` with `WP_UNINSTALL_PLUGIN` check, or `register_uninstall_hook`).
14. No invented APIs (2 points: deduct 1 per invented function/prop, minimum 0).

Max: 15
