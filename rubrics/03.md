# Rubric 03: Maintenance Banner (Settings and Options API)

The prompt describes outcomes only and names no APIs. Score whether the code chose correct, current WordPress APIs. Give full credit for an equivalent current API, and 0 for a deprecated, legacy or invented one. Name what was used in each reason.

## Expected doc surfaces
- Complex: Settings API (`register_setting`, `add_settings_section`, `add_settings_field`, `settings_fields`, `do_settings_sections`, `add_settings_error`)
- Non-general: `register_setting` with `show_in_rest` + schema (`/wp/v2/settings`); `useEntityRecord` / `saveEditedEntityRecord` on root/site
- `add_options_page`, `wp_kses`, `sanitize_hex_color`, `wp_roles()`
- `registerPlugin` / `PluginSidebar`, `canUser`
- `wp_body_open`, `uninstall.php`

## Criteria (1 point each unless noted)
1. Page under Settings via `add_options_page` with `manage_options`.
2. Settings stored through `register_setting` with a `sanitize_callback` and `default` (not hand-saved with `update_option` on POST).
3. Exposed to the core REST API with `show_in_rest` and a schema covering every field.
4. Form built with the Settings API (sections, fields, `settings_fields()`, `do_settings_sections()`, posting to `options.php`).
5. Sanitizing: boolean on/off, message via `wp_kses` with an allowed list, colour via `sanitize_hex_color`, datetimes validated, roles limited to real roles.
6. End-before-start reported with `add_settings_error()` and the bad value not saved.
7. Field output escaped.
8. Editor panel registered with `registerPlugin` + `PluginSidebar` (or document setting panel).
9. Editor reads and saves through core-data on root/site (`useEntityRecord` / `useEntityProp` + `saveEditedEntityRecord`).
10. Panel hidden from users who can't manage options (`canUser` via `useSelect`).
11. Front end on `wp_body_open` (or equivalent), checks on/off, time window in site timezone, and roles.
12. Banner output escaped (`wp_kses_post` / `wp_kses`, `esc_attr`).
13. Uninstall deletes the option (`uninstall.php` with `WP_UNINSTALL_PLUGIN` or `register_uninstall_hook`).
14. No invented or deprecated APIs (2 points: deduct 1 per instance, minimum 0).

Max: 15
