# Rubric 04: Smart Media Markup (WP HTML API)

## Doc surfaces the prompt depends on
- Complex: `WP_HTML_Tag_Processor` (`next_tag`, `get_attribute`, `set_attribute`, `add_class`, bookmarks, `get_updated_html`) and `WP_HTML_Processor`
- Non-general: `render_block_{$name}` dynamic filter; `register_block_type_args` filter
- JS hooks: `blocks.registerBlockType`, `editor.BlockEdit`, `createHigherOrderComponent`
- InspectorControls, ToggleControl
- `wp_parse_url` / `home_url` for host comparison

## Criteria (1 point each unless noted)
1. Uses `render_block_core/image`, `render_block_core/gallery`, `render_block_core/cover` filters with the `( $block_content, $block )` signature.
2. Uses `WP_HTML_Tag_Processor` / `WP_HTML_Processor`, no regex or DOMDocument for the transforms.
3. Adds `decoding="async"` only when missing (`get_attribute` null check).
4. Caption-as-alt: reads figcaption text correctly (HTML Processor, or bookmarks + text extraction) and only fills an empty alt when `smartMediaCaptionAsAlt` is true.
5. Alt value is plain text (tags stripped / decoded); `set_attribute` handles escaping (no double-escaping with `esc_attr`).
6. Adds class `has-smart-media` to the outer figure with `add_class`.
7. External links: compares host with `wp_parse_url( home_url() )`, merges `noopener` into existing `rel` without duplicates.
8. Returns `get_updated_html()` (or `__toString()`).
9. PHP attribute registration through `register_block_type_args` scoped to `core/image`.
10. JS `blocks.registerBlockType` filter adds the attribute only to `core/image`.
11. `editor.BlockEdit` HOC with `createHigherOrderComponent` adds a ToggleControl in InspectorControls only for `core/image`.
12. Editor script enqueued properly (`enqueue_block_editor_assets` with asset file).
13. tests/ folder with example input/output for each transform.
14. No invented APIs (2 points: deduct 1 per invented method, e.g. a nonexistent `get_inner_text()`, minimum 0).

Max: 15
