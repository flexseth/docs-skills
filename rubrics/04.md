# Rubric 04: Smart Media Markup (WP HTML API)

The prompt describes outcomes only and names no APIs. Score whether the code chose correct, current WordPress APIs. Give full credit for an equivalent current API, and 0 for a deprecated, legacy or invented one. Name what was used in each reason.

## Expected doc surfaces
- Complex: `WP_HTML_Tag_Processor` (`next_tag`, `get_attribute`, `set_attribute`, `add_class`, bookmarks, `get_updated_html`) and `WP_HTML_Processor`
- Non-general: `render_block_{name}` filters; `register_block_type_args`
- JS block filters: `blocks.registerBlockType`, `editor.BlockEdit`, `createHigherOrderComponent`
- InspectorControls, ToggleControl; `wp_parse_url`, `home_url`

## Criteria (1 point each unless noted)
1. Changes HTML at render time with `render_block_core/image`, `/gallery`, `/cover` (or `render_block` with a name check), leaving saved content alone.
2. Uses the WordPress HTML API (`WP_HTML_Tag_Processor` / `WP_HTML_Processor`), not regex or DOMDocument (2 points).
3. Sets `decoding="async"` only when no decoding attribute exists.
4. Caption-as-alt reads the figcaption text correctly and fills alt only when the toggle is on and alt is empty.
5. Alt value is plain text; `set_attribute` does the escaping (no double escaping).
6. Adds `has-smart-media` to the outer figure with `add_class`.
7. External links: host compared against the site's host; `noopener` merged into existing `rel` without duplicates.
8. Returns `get_updated_html()`.
9. Toggle attribute registered in PHP (`register_block_type_args` scoped to core/image).
10. Toggle attribute registered in JS (`blocks.registerBlockType` filter scoped to core/image).
11. ToggleControl in InspectorControls via an `editor.BlockEdit` HOC built with `createHigherOrderComponent`, only for core/image.
12. Editor script enqueued with its asset file.
13. `tests/` has input and expected output for each change.
14. No invented or deprecated APIs (2 points: deduct 1 per instance, e.g. a nonexistent processor method, minimum 0).

Max: 16
