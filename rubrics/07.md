# Rubric 07: Event RSVP (Nonces)

The prompt describes outcomes only and names no APIs. Score whether the code chose correct, current WordPress APIs. Give full credit for an equivalent current API, and 0 for a deprecated, legacy or invented one. Name what was used in each reason.

## Expected doc surfaces
- Complex: nonces (`wp_create_nonce`, `check_ajax_referer` / `wp_verify_nonce`, `wp_nonce_field`, `check_admin_referer`) and AJAX or REST submission for logged-out users
- Non-general: Block Bindings API (`register_block_bindings_source`); `WP_List_Table` bulk actions
- `wp_add_inline_script` / `wp_localize_script` / `wp_interactivity_config`
- `dbDelta`, `$wpdb->insert`, `$wpdb->prepare`
- `admin_post_` actions, `add_management_page`; `wp_send_json_*` or `WP_REST_Response`

## Criteria (1 point each unless noted)
1. Submission endpoint works for logged-out users (`wp_ajax_nopriv_` + `wp_ajax_`, or a REST route with a public permission_callback).
2. Nonce created server-side and passed to the front-end script.
3. Nonce verified on submit (`check_ajax_referer` / `wp_verify_nonce`) with the matching action.
4. Fields validated and cleaned (`sanitize_text_field`, `sanitize_email` + `is_email`, `absint` + range 1–5), errors returned to the client.
5. Table created on activation with `dbDelta()` (`upgrade.php` required, `get_charset_collate()`, correct key formatting).
6. Insert with `$wpdb->insert()` and formats; table name uses `$wpdb->prefix`.
7. Admin page under Tools (`add_management_page`) with `manage_options`.
8. List built on `WP_List_Table` with columns, checkbox column and bulk actions.
9. Bulk delete checks capability and nonce, deletes with prepared queries.
10. CSV download through an `admin_post_` action, capability and nonce checked, correct headers, exits.
11. RSVP count in a Paragraph via the Block Bindings API (`register_block_bindings_source` on `init`, post ID from context) (2 points; 0 for a shortcode, a custom block or a content filter).
12. Front-end script submits without reload and shows success or error.
13. Escaping in render.php and the admin table.
14. No invented or deprecated APIs (2 points: deduct 1 per instance, minimum 0).

Max: 16
