# Rubric 07: Event RSVP (Nonces)

## Doc surfaces the prompt depends on
- Complex: nonces (`wp_create_nonce`, `check_ajax_referer`, `wp_nonce_field`, `check_admin_referer`) and AJAX in plugins (`wp_ajax_`, `wp_ajax_nopriv_`)
- Non-general: Block Bindings API (`register_block_bindings_source`); `WP_List_Table` bulk actions
- `wp_add_inline_script` / `wp_localize_script`
- `dbDelta`, `$wpdb->insert`, `$wpdb->prepare`
- `admin_post_` action, `add_management_page`
- `wp_send_json_success` / `wp_send_json_error`
- block.json + render.php

## Criteria (1 point each unless noted)
1. Both `wp_ajax_event_rsvp_submit` and `wp_ajax_nopriv_event_rsvp_submit` hooked.
2. Nonce created with `wp_create_nonce()` and passed via `wp_add_inline_script()` / `wp_localize_script()` with the ajax URL.
3. Handler calls `check_ajax_referer()` with the matching action and field name.
4. Fields sanitized and validated (`sanitize_text_field`, `sanitize_email` + `is_email`, `absint` + 1–5 range), errors via `wp_send_json_error()`.
5. Table created on activation with `dbDelta()` (correct formatting: two spaces after PRIMARY KEY, `$wpdb->get_charset_collate()`, requires `upgrade.php`).
6. Insert with `$wpdb->insert()` and a formats array; table name uses `$wpdb->prefix`.
7. Admin page under Tools via `add_management_page` with `manage_options`.
8. `WP_List_Table` subclass with `prepare_items`, columns, `column_cb`, `get_bulk_actions`.
9. Bulk delete checks capability and nonce (`check_admin_referer` with `bulk-{plural}` or custom `wp_nonce_field`), deletes with prepared queries.
10. CSV export via `admin_post_` action, nonce-checked, capability-checked, proper headers, exits.
11. `register_block_bindings_source( 'event-rsvp/count', [ 'label' => ..., 'get_value_callback' => ... ] )` on `init`, using the block instance/context to get the post ID.
12. Front-end script handles submit with fetch/FormData, shows success/error.
13. Escaping in render.php and the admin table output.
14. No invented APIs (2 points: deduct 1 per invented function/arg, minimum 0).

Max: 15
