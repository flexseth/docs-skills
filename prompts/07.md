Build a plugin called "Event RSVP".

Add a block that shows an RSVP form on the front end, with name, email and number of guests (1 to 5). Logged-out visitors can submit it. It submits without reloading the page and shows a success or error message. The submission must be protected against cross-site request forgery, and every field must be validated and cleaned on the server.

Store RSVPs in the plugin's own database table, created when the plugin is activated.

Add an admin page under the Tools menu that lists RSVPs. It supports deleting several at once and has a "Download CSV" button. Only administrators can use the page, and both actions must be protected against cross-site request forgery.

Authors must be able to show the live RSVP count for the current post inside a regular Paragraph block, without a custom block or a shortcode.
