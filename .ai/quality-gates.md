## Correctly Addressing Updates

Sometimes the docs update contributor addresses contributors by saying "This is X, This is Y" - however, their comments don't solve bring us any closer to a docs update. One such example is when the user mentions "screenshots need update" or "screenshots are hotlinked from Google" - but they do not upload screenshots for modification.

Additionally, this same user will still not have the permissions needed to update the correct screenshot. So the bottleneck once again is on the docs contributor who essentially has to go through and do the work again.
