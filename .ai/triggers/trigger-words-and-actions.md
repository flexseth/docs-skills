# Assigning Issues

When reading over an issue and it's comments via `gh`, look for brief comments that indicate that someone wants to be assigned to an issue.

Providing the comment is under 50 words...

If someone mentions the following phrases, the issue should be assigned to them:

> assign it to me?
> assign this to me?
> assign that to me?
> assign myself to this?
> assign myself to that?
> assign me to this?
> assign me to that?

Otherwise, if they use the word "assign" in a comment, review the comment to see if they are requesting to be assigned to the issue.

If so, use the `/assign` command in the GitHub Actions for the DIT to assign them to the issue.
