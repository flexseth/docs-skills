## Issue Types
- remove [HelpHub] or [DevHub] tags from issue titles - they are redundant since the issue type is indicated elsewhere.

## remove labels for HelpHub and DevHub
- Migrate HelpHub issue label to **end user docs** issue type
- Migrate DevHub issue label to **developer docs** issue type

## Brief description of issue types

> **End user docs:** AKA "HelpHub" - Docs and Guides on wordpress.org, intended for the general WordPress user. 
> **Developer docs:** AKA "DevHub" - Docs intended for developers, typically found in the Developer Handbook.
